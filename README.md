# 🤖 Jarvis Terminal

A custom terminal built in C++ inspired by J.A.R.V.I.S from Iron Man.
Type commands and Jarvis responds!

## ⚡ Features

- Custom command interface
- Real time clock and date
- Dynamic bot name changing
- Echo messages like a real terminal
- Cross platform clear (cls/clear)
- Game menu (coming soon!)

## 📥 Installation

1. Clone the repository:
```bash
git clone https://github.com/HappyKn1ght/Jarvis.git
```

2. Navigate to project folder:
```bash
cd Jarvis
```

## 🚀 How to Compile & Run

**Using G++:**
```bash
g++ jarvis.cpp -o jarvis && ./jarvis
```

## 📋 Available Commands

| Command | Description |
|---|---|
| `hi/hello` | Jarvis greets you |
| `time` | Shows current time |
| `date` | Shows current date |
| `cls/clear` | Clears the screen |
| `about` | About Jarvis |
| `change` | Change Jarvis name |
| `echo <message>` | Displays your message |
| `game` | Game menu (coming soon!) |
| `exit` | Quit Jarvis |
